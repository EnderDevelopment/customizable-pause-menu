# Customizable Pause Menu

A highly customizable pause menu system for FiveM servers.

## Features

- Highly customizable UI with configurable colors and text
- Save and load user preferences from a database

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start pauseMenuSystem` to your server.cfg file

## Usage

1. Press the configured key (default: ESC) to open the pause menu
2. Customize the UI settings as desired
3. Click 'Save Settings' to save your preferences

## Configuration

Edit the `config.lua` file to customize:

- Menu title and subtitle
- Background, text, and button colors
- Database settings
